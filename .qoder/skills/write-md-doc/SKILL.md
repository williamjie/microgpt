# Write MD Doc

将用户要求生成的 Markdown 文档写入文件时的统一输出规范。

## 输出位置

写入当前项目根目录的 `docs/` 目录；若 `docs/` 不存在，先创建该目录。

## 文件命名

格式：`yyyyMMdd-HHmm-主题.md`（年月日-小时分钟-主题.md）

- 日期与时间之间用连字符 `-` 分隔，例如 `20260917-1530-项目分析.md`
- 主题为 2~8 字的简短中文关键词，概括文档内容
- 时间取当前系统时间（小时为 24 小时制，两位数）

## 示例

| 场景 | 文件名 |
|------|--------|
| 项目分析报告 | `docs/20260917-1530-项目分析.md` |
| 测试报告 | `docs/20260917-0945-测试报告.md` |
| 接口设计说明 | `docs/20260917-2100-接口设计.md` |

## 注意事项

- 同一主题多次写入时，按当前时间生成新文件，不覆盖旧文件
- 只规范输出位置和命名，文档内容结构根据用户要求自由组织
- 除写入文件外，在回复中告知用户文档的保存路径
