## 四、讲解稿（口播用）

### 4.1 演示大厅 `demos_index.html`（1 分钟）

1. 打开大厅，说明：这些页面是「可运行的教具」，对应 `microgpt.py` 各部分。  
2. 建议顺序：分词 → 损失 →（已有）自动微分 → Softmax / RMSNorm / Attention → 训练一步。  
3. 强调：先点下一步看动画，再回代码找同一概念。

---

### 4.2 分词 `tokenizer_demo.html`（约 5 分钟）

| 步骤 | 你做什么 | 你说什么 |
|------|----------|----------|
| 0 | 打开页面 | 神经网络只认数字，不认字母。所以要把名字变成编号序列。 |
| 1 | 点下一步：展示字母表 | 数据集里出现过的字符排序后编号：a=0 … z=25。 |
| 2 | 点下一步：出现 BOS | 多一个特殊符号 BOS，像哨声：表示「名字开始/结束」。id 通常是 26。 |
| 3 | 点下一步：输入 emma | 训练时名字两边都加 BOS：`[BOS, e, m, m, a, BOS]`。 |
| 4 | 点下一步：显示 id 列表 | 例如 `[26, 4, 12, 12, 0, 26]`。模型学的是「根据前面的数字，猜下一个数字」。 |
| 5 | 收尾 | ChatGPT 也是同一思路，只是用了更聪明的子词分词（BPE），词汇表更大。 |

对应代码：`microgpt.py` 第 2 部分。

---

### 4.3 交叉熵 `loss_demo.html`（约 5 分钟）

| 步骤 | 你做什么 | 你说什么 |
|------|----------|----------|
| 0 | 打开页面 | 训练的目标不是「背下名字」，而是「猜对下一个字母时少吃惊」。 |
| 1 | 展示概率条 | Softmax 后得到每个字母的概率，加起来等于 1。 |
| 2 | 标出正确答案 | 假如正确答案是 `m`，只看 `p(m)`。 |
| 3 | 显示 loss = -log p | 概率越接近 1，loss 越接近 0；概率很小，loss 很大。 |
| 4 | 对比随机 | 27 选 1 瞎猜时，平均 loss ≈ 3.3，这就是训练刚开始的水平。 |
| 5 | 收尾 | 训练一千步，就是反复让正确字母的概率变大，从而把 loss 压下去。 |

对应代码：训练循环里 `loss_t = -probs[target_id].log()`。

---

### 4.4 训练一步 `train_step_demo.html`（约 8 分钟）

| 步骤 | 阶段名 | 你说什么 |
|------|--------|----------|
| 0 | 就绪 | 一步训练 = 拿一个名字，走完「前向 → 损失 → 反向 → 更新」。 |
| 1 | 取文档 | 取出一个名字（如 emma），打乱顺序是为了别只背位置。 |
| 2 | 分词包裹 | 变成 `[BOS, e, m, m, a, BOS]`。 |
| 3 | 前向传播 | 逐位置问模型：下一个字母概率分布是什么？（内部会建 KV Cache） |
| 4 | 算损失 | 每个位置算 `-log p(正确答案)`，再平均成一个标量 loss。 |
| 5 | 反向传播 | `loss.backward()`：顺着计算图，给每个参数填上梯度 `.grad`。 |
| 6 | Adam 更新 | 用梯度微调 4192 个参数（比裸减梯度更稳）。 |
| 7 | 清零梯度 | `p.grad = 0`，否则下一步会脏累加。 |
| 8 | 循环 | 重复约 1000 步；然后冻结参数，进入推理生成新名字。 |

对应代码：`microgpt.py` 第 6～7 部分。

---

### 4.5 已有四页（复习口播要点）

| 页面 | 一句话 |
|------|--------|
| autograd | Value 记住「怎么算出来的」；backward 用链式法则填梯度。 |
| softmax | logits → 概率；温度低更尖、高更平。 |
| rmsnorm | 把向量「音量」调稳，训练更不容易炸。 |
| attention | Q 查历史 K，权重加权 V；KV Cache 避免重复算历史。 |
