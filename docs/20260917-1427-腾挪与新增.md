# 后训练是"腾挪"还是"新增"？——固定参数空间里的表达选择

> 缘起：读完 [20260917-1330-两方向解析.md](20260917-1330-两方向解析.md) 和 [20260917-1335-算力战略.md](20260917-1335-算力战略.md) 后的自然追问——
> *"总参数不变的情况下，后训练的对齐，也只是在腾挪啊。"*
>
> **先给结论：这个判断基本正确**——后训练在数学上确实是在固定参数空间里"腾挪"。但"腾挪"这个词低估了它威力的一半。本文分三层讲透。
>

## 一、第一层：对，数学上就是"腾挪"

参数个数（房间面积）在预训练结束时就焊死了。后训练改的只是**这数千亿个数值的取值组合**——从参数空间的一个点，挪到另一个点。它：

- 不能增加参数（房间不变大）
- 不能大规模注入新知识（装修材料不新增）
- 不能突破 [容量上限](20260917-1320-容量上限.md) 里的天花板

所以从纯数学视角看：**后训练 = 在固定的空间里，寻找一个"行为更好"的新坐标点**。说它是腾挪，没有错。

这也精确解释了 [两方向解析](20260917-1330-两方向解析.md) 的核心论断：为什么"在别人的 500B 上继续后训练"永远追不上"自己 10T 重新预训练"——腾挪的手艺再好，也变不出更大的房间。

---

## 二、第二层：为什么"腾挪"威力这么大？——知识早已以"叠加态"存在

关键洞察：**预训练模型其实"已经会"很多东西，只是不稳定、不可靠、藏在一堆可能行为里。**

回想 base model 的训练：它读过的文本里**本来就包含**对话、问答、代码、推理过程。这些模式全部被压进了参数里——但 base model 是个"文档补全器"，它可能以任何风格接龙：接着写 FAQ、接着写小说、接着写论坛吵架帖……

后训练做的事，是从这个"所有可能行为的海绵"里，**筛选并放大其中一种**："当用户提问时，以助人的方式回答"这个模式在参数空间里本来就存在，SFT/RL 把模型稳稳地钉在那个区域，让它**每次都走这条路**。

### 三个比喻

| 比喻 | 对应关系 |
|------|----------|
| **图书馆** | 预训练盖了馆、进了书（知识全在）；后训练培养管理员（怎么找、怎么答、怎么有礼貌）。管理员没添一本书，但"无序仓库"和"一流图书馆"的差距天壤之别 |
| **收音机** | 所有电台本来就在广播（能力已在参数里）；后训练只是把旋钮拧到固定频道、并把音量调大 |
| **演员** | 同一个演员（同一组参数），预训练给了他满腹技能，后训练是导演选定角色——"台词没变多，但演出判若两人" |

### 一个实证

base model 其实**用 few-shot 提示也能完成对话任务**——说明对话能力预训练时就有了。后训练的贡献是把"提示工程才能逼出来的能力"变成"默认稳定输出的能力"。

**所以"腾挪"的准确理解是：不是搬运知识，而是选择哪种已存在的能力被表达。**

"表达什么"和"有什么"一样值钱——一个满腹经纶但从不好好说话的人，和一个善于表达的人，在别人眼里是两个智力等级。

## 三、第三层：诚实的补充——后训练也不完全是"纯腾挪"

科学上的最新认识（即 [算力战略](20260917-1335-算力战略.md) 中的 RL 扩展趋势）是：后训练的影响是**一个光谱**，而不是二元的"要么纯腾挪、要么学新东西"：

```text
行为塑形 ←────────────────────────→ genuine 新能力
(SFT 学格式风格)      (RL 学推理策略)      (超大规模 RL)
  90% 腾挪           腾挪为主 + 少量新增            争议区
```

- **SFT 阶段**：基本是腾挪 + 少量新知识（训练数据里的事实能记一点，但塞新知识效率很低，塞多了还容易"背伤"旧能力——灾难性遗忘，见 [两方向解析](20260917-1330-两方向解析.md) 第 3.4 节）
- **RL 阶段（o1/o3 那类）**：学界主流看法是"**激发为主 + 部分真正新增**"——模型学会的"长链条分步推理、自我检查、回溯"等策略，预训练里有雏形，RL 把它们放大并组合成可靠的推理行为。但超大算力的 RL 是否创造了参数空间里"原本表达不出来"的能力，仍是开放的研究问题
- **关键证据**：RL 训练出的模型去做 RL 没见过的任务，常常也变强了——说明学到的不只是"某一题的搬法"，而是更通用的"搬法的方法论"

## 五、总结

1. **腾挪论正确**：参数不变，后训练只能在固定参数空间里移动坐标点，变不出新容量
2. **但腾挪 ≠ 小事**：预训练把海量能力以"叠加态"压进参数，后训练选择**哪种能力被稳定表达**——表达本身值千亿美金
3. **光谱而非二元**：SFT ≈ 90% 腾挪；RL 是"激发为主 + 部分真正新增"；超大规模 RL 是否产生真新能力仍是开放问题
4. **行业含义**：RL 扩展的本质是"同一间房子里，把搬家的手艺做到极致"——这是预训练撞墙后的新扩展轴

> 一句话收束：**你说得对——参数不变，后训练就不能变出新东西，它是同一种子里的不同表达。但要补一句：同一颗种子长成什么样，表达本身就价值连城。base model 是"什么都会一点、什么都不稳"的原石，对齐是从原石里切出"稳定、有用、可控"的那一面——而切工越好，同一间房子里能过出的日子就越好。**
