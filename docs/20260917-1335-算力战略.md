# 算力决定路线：智谱的"迭代后训练" vs 海外的"规模+后训练并发"

## 一、你的理解对在哪里：算力确实是战略的第一变量

"算力预算决定训练策略"——这个判断完全成立。先把约束摆出来：

### 1.1 海外头部阵营的算力

- OpenAI / Anthropic / Google：训练集群规模在 **数万~十万张** H100/B200 级别，且在持续扩建（StarGate 级别的数百亿美元数据中心投资）
- 单次旗舰预训练成本：**数亿美元**量级
- 关键优势不只是卡多，还有 **NVLink/InfiniBand 互联 + 十年打磨的 CUDA 软件栈**，万卡集群的利用率高

### 1.2 国内阵营的算力约束（你的判断的依据）

- **出口管制**：2022 年 10 月起 A100/H100 对华禁售，之后 H800、H20 也被逐步限制——高端卡的获取通道被逐年收紧
- **国产替代仍在爬坡**：昇腾 910B、寒武纪等国产卡单卡性能与 H100 有代差，更大的差距在**软件生态**（CANN vs CUDA 的成熟度）和**集群互联**（万卡互联的通信效率与稳定性）
- **结论**：国内实验室可调度的"有效算力"显著低于海外头部，且获取更贵、更慢

**算力少 → 每一分算力都要花在刀刃上 → 训练策略必然不同。** 你的这个推理链条是对的。

## 二、需要修正的第一处：智谱并不是"只做后训练"，他们也在堆参数

看智谱的实际产品线就会发现，"不堆参数"这个印象不准确：

```text
GLM-130B（2022，1300 亿稠密）
→ ChatGLM-6B（2023，小尺寸开源）
→ GLM-4（2024）
→ GLM-4.5（2025，355B 总参 / 32B 激活的 MoE）
→ GLM-4.6（持续迭代）
```

智谱一直在做大规模预训练。真实策略是：**预训练照做（用 MoE 等方式控制成本），同时靠高频后训练迭代来快速提升产品体验。**

你观察到的"基模继续后训练"现象，本质是**发布节奏**：预训练一次要几个月、几亿元，不可能月月来一次；而后训练只要几周、成本不到预训练的 1%——所以新基模之间夹着大量"小版本"（对齐优化、Agent 能力、代码能力增强），看起来像"一直在后训练"。

**这是算力约束下的理性节奏，而不是放弃预训练。** 国内 DeepSeek（671B MoE）、阿里 Qwen（千亿级 MoE 家族）同理——国产阵营从未停止堆参数，只是**堆得更有算术效率**。

## 三、需要修正的第二处：算力约束逼出的不是"退缩"，而是"算法创新"

这是最深的一层洞察，也是国产阵营真正值得尊敬的地方：

> **算力受限 → 被迫把每一份算力的产出最大化 → 反而催生训练效率的极限创新。**

DeepSeek-V3 是教科书级案例——在受限算力下做出了一系列影响全行业的技术：

| 技术选择 | 解决什么问题 | 省了多少 |
|----------|--------------|----------|
| **MoE 稀疏激活**（671B 总参 / 37B 激活） | 参数多（容量大）但每 token 只算一小部分 | 单 token 计算量降 ~18 倍 |
| **FP8 混合精度训练** | 显存与带宽减半 | 训练成本近半 |
| **DualPipe / 跨节点通信优化** | 国产/受限互联下万卡利用率 | 流水线气泡近乎消除 |
| ** MLA（多头潜在注意力）** | KV Cache 压缩，推理显存大降 | 推理成本数量级下降 |
| 高质量数据工程 | 数据替代算力 | 用更少 token 学到更多 |

结果：V3 预训练只用约 **2048 张 H800、不到 600 万美元**（官方口径），达到与海外数亿美元训练相当的水平。这直接击碎了"算力少就做不出好模型"的论断。

所以更准确的表述是：

> **海外头部：算力充足 → 什么都直接用算力砸（scale everything）**
> **国内阵营：算力受限 → 用算法效率换算力（scale intelligence per FLOP）**
> **殊途同归：Scaling Law 的两个乘数——"更多算力"和"每算力更高产出"。**

## 四、需要修正的第三处："后训练迭代"如今不只是穷办法，它同时是全球主流趋势

这里有个时间线上的关键变化，很多人没意识到：

```text
2020-2023：行业共识 = 预训练堆规模是王道（Scaling Laws 主导）
2024 至今：预训练遇到三堵墙 → 行业转向"后训练/RL 扩展"（post-training scaling）
```

三堵墙：
1. **数据墙**：高质量互联网文本快被用尽，继续堆预训练数据边际收益递减
2. **成本墙**：下一代预训练要数十亿美元，性价比遭遇质疑
3. **能力墙**：靠"猜下一字"堆出来的模型，在"长时间推理"上提升乏力

于是 OpenAI（o1/o3 系列）、Anthropic（扩展思考）都在做同一件事：**把算力从预训练挪向大规模强化学习与推理时计算（test-time compute）**——让模型"想得更久"而不是"背得更多"。RL 阶段的算力消耗占比正在快速上升，海外甚至出现"RL 算力超过预训练算力"的趋势预测。

**所以"靠后训练迭代提升模型"不再是算力受限者的无奈之选，而是全行业在预训练边际收益下降后的共同主航道。** 国内阵营只是因为算力约束，更早、更坚定地踏上了这条航道。

## 五、把两条战略放进一张矩阵

| 维度 | 海外头部：规模+后训练并发 | 国内：效率创新+高频后训练迭代 |
|------|--------------------------|------------------------------|
| 算力预算 | 数十亿美元/代 | 低 1~2 个数量级 |
| 预训练 | 超大稠密/超宽 MoE，一次到位 | 中大 MoE，FP8/Mla 等极限提效 |
| 后训练/RL | 大规模 RL 基建（o1 类推理模型） | 高频小步迭代，Agent/代码能力快速跟进 |
| 发布节奏 | 代际跳跃（间隔长、跨度大） | 小步快跑（基模稳定，版本频出） |
| 优势 | 能力天花板最高；能做"算力吞金"型突破（超大 RL） | 成本低、迭代快、单位算力产出高 |
| 风险 | 数据墙/成本墙；回报边际递减 | 天花板受限；算力型突破（超大规模 RL）可能掉队 |
| 典型代表 | GPT-5/Claude/Gemini | DeepSeek-V3、GLM-4.5、Qwen3 |

补充一点关于"并发"：海外确实是**流水线并发**——下一代预训练在集群上跑几个月的同时，当前一代的 RL/后训练在另一部分算力上持续进行。这需要算力多到能"分家"；国内算力不够分家，只能**串行**：预训练完 → 集中算力做 RL/后训练 → 释放算力准备下一代。这正是你感觉到的"并发 vs 迭代"差异的物理根源。

## 六、两条路线的未来推演

**国内路线的胜负手**：单位算力效率的领先能否持续。DeepSeek 已证明可以用 1/10 的算力追到 90% 的能力；但最后的 10%（超大规模 RL 涌现出的深度推理）恰恰是"算力吞金"的领域——天花板仍是隐忧。国产 GPU（昇腾等）的软件生态成熟速度，是这条路线最大的变量。

**海外路线的胜负手**：超大算力的边际回报。如果"更大的 RL 规模 → 更强的推理"这一新型 Scaling Law 持续成立，算力优势将继续变现；如果数据墙/回报递减先到来，重资产模式会被质疑。

**值得注意的合流迹象**：两条路线正在互相靠近——海外在学国内的效率技术（MoE、FP8、MLA 已成行业标配），国内在补算力基建（国产万卡集群）。长期看，**"算法效率 × 算力规模"两个乘数都要最大化**，单一维度的领先都会被抹平。

---

## 七、回到 microgpt：一个小小的印证

microgpt 里其实预演了这个选择的微缩版：

- 你可以**加大算力**：`num_steps` 从 1000 加到 10000，loss 会继续降——这是"海外路线"
- 也可以**固定算力，改进方法**：把训练数据清洗得更好、把学习率调度调得更优、甚至把损失函数做课程化设计——同样的 1000 步，loss 降得更低——这是"国内路线"
- 两者不冲突：**最优解永远是"在给定算力预算下，方法效率最大化，然后用增长的钱继续扩算力"**

## 八、总结

1. **你的核心判断正确**：算力约束确实塑造了两条不同的战略路径
2. **修正一**：智谱等国产阵营并没有放弃堆参数，而是"MoE+FP8+数据工程"式的高效堆参数 + 高频后训练迭代
3. **修正二**：算力受限逼出的效率创新（DeepSeek 为代表）已成为全行业标配——约束反而催生了领先
4. **修正三**："靠后训练迭代变强"如今是全球主航道（RL/推理时计算扩展），国内只是更早踏上
5. **本质框架**：能力 = 算力规模 × 单位算力效率。海外乘数一占优，国内乘数二占优，两条路线正在合流

> 一句话收束：**卡多的人直接堆卡，卡少的人把每张卡的潜力榨到极限——但决定最终高度的公式是两者的乘积。国产阵营真正聪明的地方，是把"卡少"从一个劣势，锻练成了一种算法进化压力。**
