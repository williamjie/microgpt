# 资深级学习指南（Senior）

> 适用：已读懂代码，想**理解“为什么这样设计”**并能扩展/移植的人。
> 目标：讲清原理，能在 microgpt 上做加法（加层、换数据、移植、接可视化）。

---

## 一、通俗易懂

### 1. 自动微分：像倒放录像
普通数字是一张“照片”（只有结果）；microgpt 的 `Value` 是一段“录像”（记录了整个计算过程，能倒放）。每个运算只记两件事：结果是多少、以及“我对每个输入有多敏感”（局部梯度）。
反向传播就是**从最终 loss 一路往回倒带**：用“链式法则”把每一处的敏感度相乘传回去。一个值被多处使用时（图分叉），各路梯度**加起来**——就像一条河分成几支流，总水量是各支之和。

### 2. 注意力：让字母互相“传话”
当前字母会问：“过去哪些字母和我相关？”它生成三个东西：
- **Q（查询）**：我在找啥信息？
- **K（钥匙）**：我这里有什么信息？
- **V（值）**：你选中我，我能给你啥？
Q 和每个历史 K 做点积得到“相关度”，softmax 变成权重，再按权重把历史 V 加起来——这就是“看一眼过去”。
点积要除以 `√头维度`，否则数值太大、softmax 太尖、梯度学不动。

### 3. KV Cache：不只是推理才用
microgpt 一次只算一个字母，所以必须把前面每个字母的 K、V 存起来（KV Cache），下一个字母才能“看到”历史。而且这些是还在计算图里的活节点，反向传播也穿过它们——这和 PyTorch 把并行藏在矩阵里不同，但本质一致。

### 4. Adam：带“记忆”的调旋钮
普通梯度下降只看眼前坡度；Adam 还记两样：
- **m（动量）**：最近坡度的平均 → 方向更稳，不左右晃。
- **v（自适应）**：最近坡度平方的平均 → 每个旋钮有自己的步长（一直大变的少走点，一直小变的多走点）。
前几步 m、v 偏小，所以用 `m_hat/v_hat` 放大一下（偏差修正）。

### 5. 这级的“毕业考”
白板上画出 `a*b + a` 的计算图并手算 `a.grad/b.grad`；解释为何训练也用 KV Cache；说清 Adam 比普通梯度下降聪明在哪。

## 二、专业口吻

### 1. 自动微分与链式法则
`Value` 以 6 个基本运算（`+ * ** log exp relu`）组合表达整网；每运算记录 `_children` 与 `_local_grads`。`backward()` 先拓扑排序，置 `loss.grad=1`，逆序应用：
```
∂L/∂child += ∂v/∂child · ∂L/∂v      （链式法则，分支处累加 +=）
```
分叉节点梯度为各路径贡献之和（多元链式法则）。

### 2. 缩放点积注意力
单头注意力分数：`attn = softmax(QKᵀ / √d_h) V`。缩放因子 `1/√d_h` 使点积方差归一为 1，避免 `d_h` 增大导致 softmax 饱和、梯度消失。多头将 `n_embd` 切分为 `n_head` 个 `head_dim` 子空间，并行捕获不同类型依赖后拼接。

### 3. KV Cache 在训练期的角色
microgpt 无 batch/时间并行，逐 token 递推，故显式维护 `keys/values` 列表；这些 `Value` 节点属于当前计算图，反向传播经其回传梯度。生产实现将 KV 隐藏于向量化注意力中，概念等价。

### 4. 归一化与残差
- **RMSNorm**：`x̂ = x / √(mean(x²) + ε)`，相较 LayerNorm 省去均值中心化，计算更轻。
- **残差连接** `x = f(x) + x`：提供梯度直通路径（防梯度消失）并使每层只需学“增量”。

### 5. Adam 更新与偏差修正
```
m = β1·m + (1-β1)·g
v = β2·v + (1-β2)·g²
m̂ = m/(1-β1ᵗ),  v̂ = v/(1-β2ᵗ)
θ ← θ - lr·m̂/(√v̂ + ε)
```
因 `m,v` 初始化为 0，早期估计有偏，`m̂/v̂` 做无偏修正；学习率线性退火。

### 6. 温度采样
推理时 `p = softmax(logits / T)`：`T<1` 分布更尖锐（更保守），`T→0` 退化为贪心，`T>1` 更平坦（更多样）。

### 7. 扩展实验建议
加层（`n_layer=3~4`）观察过拟合/减速；换 Shakespeare/中文诗体会数据分布；NumPy 张量化前向比速度；手写反向传播验证 autograd 开销（社区实测 ~40s→~5s）。
