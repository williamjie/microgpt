# 专家级学习指南（Expert）

> 适用：已吃透原理，想**把 microgpt 与工业级 LLM 打通**的人。
> 目标：看清“算法相同、工程天差地别”的全景，建立持续深入的知识地图。

---

## 一、通俗易懂

### 1. 同一个菜谱，不同的厨房
microgpt 和 ChatGPT 用的是**同一个菜谱**（预测下一个 token、采样、重复）。差别只在厨房大小：
- 食材：几万个名字 vs 整个互联网；
- 锅：4192 个参数 vs 数千亿；
- 火：你笔记本 1 分钟 vs 几千张 GPU 跑几个月；
- 后厨培训：microgpt 没有“礼貌训练”，ChatGPT 还多了“学怎么聊天”。

所以：**你在家用小锅练的手艺，和大饭店大锅做的，道理一模一样。**

### 2. 六个“长大”的步骤
1. **分词**：一个字母一个号 → 常见词直接成一个“词块”（BPE），效率翻几十倍。
2. **算梯度**：一次算一个数 → 一次算一整批数（张量），在 GPU 上并行。
3. **模型**：1 层小网络 → 上百层巨网，并加入 RoPE（更好的位置编码）、GQA（省内存）、MoE（专家混合）等新积木。
4. **训练**：一次看一个名字 → 一次看百万 token，混合精度、梯度累积。
5. **后训练**：基础模型只是“补全机器”，再加 SFT（用对话继续练）+ RL（被评分后改进），才变成聊天机器人。
6. **推理**：一个人慢慢编 → 给几百万人同时服务，靠 KV Cache 分页、量化、推测解码提速。

### 3. 它为什么慢？（一眼诊断）
纯 Python、一次只算一个标量、完全没并行——这是教学代价。真正的快来自：张量化、GPU、内核融合、批处理。

## 二、专业口吻

### 1. 六大跃迁对照（microgpt → 工业 LLM）
| 维度 | microgpt（教学） | 工业级 LLM |
|------|------------------|------------|
| 分词 | 字符级，vocab=27 | 子词 BPE/SentencePiece，vocab≈10⁵ |
| 自动微分 | 标量 `Value`，纯 Python | 张量 autograd，GPU/TPU，FlashAttention |
| 架构 | 4,192 参数，1 层 | 数千亿参数，100+ 层；RoPE/GQA/门控/MoE |
| 训练 | 单文档、fp32、1000 step | 大批次、梯度累积、bf16/fp8、缩放法则指导 |
| 后训练 | 无 | SFT + RLHF/RLAIF |
| 推理 | 单样本串行 | 分页 KV Cache(vLLM)、推测解码、量化、多卡 |

核心结构“注意力通信 + MLP 计算在残差流交替”保持不变。

### 2. 缩放法则与训练规模
Chinchilla 等法则指导在给定算力下分配模型参数与训练 token 数；超参（lr、warmup、衰减、weight decay）须按规模精调，错误配置在千卡训练中会浪费巨额算力。

### 3. 后训练范式
预训练基础模型为“文档补全器”而非对话者。SFT 仅将训练文档替换为策展对话；RL 阶段模型生成被评分（人/裁判模型/规则），从反馈中继续在 token 上训练。算法内核不变，数据构成改变。

### 4. 推理系统工程
服务百万用户需请求批处理、PagedAttention 管理 KV Cache、投机解码加速、int8/int4 量化降显存、张量/流水线并行。本质仍是 next-token prediction，工程目标是吞吐与延迟。

### 5. 性能剖析方法论
以 `python -m cProfile microgpt.py` 定位热点（通常为注意力点积与 `backward`）；加速杠杆：张量化（SIMD/GPU）、内核融合、批处理、去除标量 autograd 开销。
