# 入门级学习指南（Beginner）

> 适用：会一点 Python、听说过“神经网络”但没写过的人。
> 目标：不碰公式，先把程序跑起来，建立“这东西到底在干嘛”的直觉。

---

## 一、通俗易懂

### 1. 这玩意儿到底是啥？
microgpt 就是一个**“起名工厂”**。你给它看几万个真名字（比如 emma、olivia），它自己琢磨出“名字一般长啥样”，然后**编出一串听起来像真名字、但其实谁也没叫过的新名字**。

它和 ChatGPT 干的是同一件事——只不过 ChatGPT 看的不是“几万个名字”，而是“整个互联网”，模型也大了一千万倍。所以：**看懂 microgpt，你就看懂了 ChatGPT 的骨架。**

### 2. 一个最好懂的比喻：收音机旋钮
把模型想成一台老式收音机，背后有 4192 个**旋钮（参数）**。出厂时这些旋钮是随机拧的，所以一开始它“瞎编”名字。
训练的过程，就是反复做一件事：
> 听一个真名字 → 试着模仿 → 发现哪里不对 → 把旋钮微调一点点 → 下次编得像一点。

调了 1000 轮之后，旋钮就停在了一个“能编出像样名字”的位置。

### 3. 怎么跑起来（3 步）
1. 确保你的电脑装了 Python（不需要装任何第三方库）。
2. 在文件夹里打开终端，输入：`python microgpt.py`
3. 你会看到一串数字（loss）从大约 **3.3 一路降到 2.37**，最后蹦出 20 个“新名字”。

### 4. 三个一眼就懂的小实验
- 把 `temperature = 0.5` 改成 `1.0`、`2.0` 分别重跑：名字会从“正常”变“离谱”——温度越高越爱乱编。
- 把 `num_steps = 1000` 改成 `100`：loss 还没来得及学会就停了，名字会变差。
- 删掉 `input.txt` 再跑：它会自动上网把名字数据重新下载回来。

### 5. 看完这一级，你应该能答出这 4 个问题
- 模型编出的名字，为什么“听起来像真的”？（因为它学到了名字的统计规律）
- `BOS` 是干啥的？（一个“开始/结束”信号，告诉模型一个新名字从哪起、到哪止）
- loss 从 3.3 降到 2.37 说明什么？（它猜下一个字母越来越准了）
- 温度越大，结果是更“保守”还是更“发散”？（更发散、更随机）

## 二、专业口吻

### 1. 项目定位
microgpt 是一份**极简的 GPT 训练/推理参考实现**：约 200 行纯 Python、零第三方依赖，完整覆盖字符级分词、标量自动微分、GPT-2 风格 decoder-only Transformer、Adam 优化器与自回归采样。其价值在于以最小代码量暴露 LLM 的**完整算法链路**。

### 2. 数据流概览
```
   →文本数据集(≈32k 名字)
   → 字符级分词(字母↔整数 id)
   → 标量 autograd 引擎(Value 类)
   → GPT-2 风格模型(嵌入→RMSNorm→注意力→MLP→lm_head)
   → 训练循环(前向/交叉熵损失/反向/Adam)
   → 自回归采样(带 temperature 的 softmax 采样)
```

> **通俗解释**：上面那串箭头，翻译成人话就是——
> 1. **准备素材**：先攒几万个真名字当“教材”。
> 2. **翻译成机器语言**：字母计算机不认识，所以把 a/b/c… 各编个号，变成数字。
> 3. **自动算账本**：有个“智能计算器”（Value 类），能自动记住每一步怎么算的，回头好知道每个旋钮该往哪调。
> 4. **核心大脑（模型）**：把一个字母送进去，它先变成一串数字（嵌入），打扫干净（RMSNorm），跟前面的字母“对一下眼神”找关联（注意力），自己再“琢磨一下”（MLP），最后吐出 27 个分数，表示“下一个最可能是谁”。
> 5. **练手（训练）**：让它先猜、看错多少（损失）、倒推账本调旋钮（反向+Adam），反复 1000 轮。
> 6. **出题（推理）**：从“开始”信号起，按分数高低抽签决定下一个字母，一个接一个拼出新名字。

### 3. 关键规模与超参
| 项 | 值 | 说明 |
|----|----|------|
| vocab_size | 27 | 26 个小写字母 + 1 个 BOS |
| n_embd | 16 | 嵌入维度 |
| n_head | 4 | 注意力头数 |
| head_dim | 4 | 每头维度 = n_embd / n_head |
| n_layer | 1 | Transformer 层数 |
| block_size | 16 | 最大序列长度 |
| 参数总数 | 4192 | 全部为 `Value` 包装的标量 |

> **通俗解释**：这些“超参”就是这台起名机器的**设计图纸**，决定了它有多大的脑容量：
> - **vocab_size = 27**：总共就 27 个“字”（26 个字母 + 1 个“开始/结束”记号），所以模型每次只需要在 27 个里挑一个。
> - **n_embd = 16**：每个字母被表示成 16 个数字的“身份证”，数字越多（脑容量越大）能记的细节越多。
> - **n_head = 4 / head_dim = 4**：注意力像 4 个“小评委”，每人只盯 4 个角度（比如一个看前后字母、一个看名字开头），合起来更懂规律。
> - **n_layer = 1**：目前只有 1 层“思考”，层数越多想得越深（但也越慢）。
> - **block_size = 16**：最多同时“看”16 个字母的位置，够覆盖最长名字了。
> - **参数总数 4192**：就是那台收音机背后的 4192 个旋钮，训练就是反复拧它们。

### 4. 运行与可复现性
- 入口：`python microgpt.py`（无需 `pip install`）。
- 数据缺失时自动从 GitHub 下载 `names.txt`。
- `random.seed(42)` 固定随机源，保证每次运行参数初始化、数据打乱、采样结果一致，便于教学与调试。

### 5. 配套可视化（建议并行使用）
根目录 `demos_index.html` 为总入口，含 `tokenizer_demo`（字符↔id）、`softmax_demo`（logits→概率）、`loss_demo`（负对数似然）、`attention_demo`、`autograd_demo`、`rmsnorm_demo`、`train_step_demo`。

### 6. 学习路径建议
先建立整体直觉（本文件），再进入「熟练级」逐模块读代码；数学与工程对比留待「资深级」「专家级」。
