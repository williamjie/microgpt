# microgpt 初学者学习路径与计划

> 面向：有一点 Python 基础、几乎没有机器学习背景的初学者  
> 目标：跑通并真正看懂 `microgpt.py`，理解「ChatGPT 在算法上到底在干什么」  
> 预计总时长：**2～4 周**（每天 1～2 小时）

---

## 一、这个项目是什么？

**microgpt** 是 Andrej Karpathy 的教育项目：约 200 行纯 Python、零第三方依赖，完整实现 GPT 的训练与推理。

本仓库是其中文学习版，核心资产：

| 资源 | 作用 |
|------|------|
| [microgpt.py](../microgpt.py) | 中文详细注释的完整实现（唯一需要真正读懂的代码） |
| [README.md](../README.md) | Karpathy 博客中文翻译，按模块讲解 |
| `input.txt` | 约 3.2 万个英文名字（训练集） |
| 4 个 HTML 演示 | 注意力 / 自动微分 / RMSNorm / Softmax 可视化 |
| `docs/` 目录 | 本仓库已有的专题笔记（可按阶段查阅） |

**一句话**：给模型看几万个名字 → 它学会「名字长什么样」→ 编出新名字。ChatGPT 做的是同一件事，只是数据更大、模型更大。

代码主线（永远挂在脑子里）：

```text
数据 → 分词 → 自动微分 → 参数 → GPT 架构 → 训练 → 推理
```

## 二、学习前准备

### 必备基础（不够就先补 2～3 天）

- Python：变量、列表、字典、函数、`for` 循环、类的基本用法
- 会用命令行：进入项目目录、运行 `python microgpt.py`
- 高中数学即可：加减乘除、指数、对数；**不要求**会微积分证明（后面用直觉理解链式法则）

### 环境

```bash
# 只需 Python 3，无需 pip install
cd d:\self_code\microgpt
python microgpt.py
```

预期：约 1 分钟跑完；loss 从约 3.3 降到约 2.3；结尾打印 20 个「编造」的名字。

### 推荐学习姿势

1. **先跑通，再读懂，再改一改**——不要一上来死磕数学  
2. **每次只啃一块**（数据集 / 分词 / Value / 注意力 / 训练 / 推理）  
3. **写笔记**：用自己的话复述「这一段在干什么」  
4. 看不懂就先打开对应 HTML 演示，建立画面感后再回代码

### 第 1 周 —— 数据、分词、损失直觉（入门）

**目标**：弄清「模型吃什么、学什么、什么叫学得好」。

#### Day 1～2：数据集 + 分词器

- 读 `microgpt.py` 第 1、2 部分  
- 对照 README「数据集」「分词器」章节  
- 打开 `input.txt` 看几行真实数据  

**动手小实验**：

```python
# 在 Python 里自己试（或临时改脚本打印）
# 1. 统计有多少个名字、最长名字多长
# 2. 打印 uchars、BOS、vocab_size
# 3. 手动把 "emma" 转成 token 列表：[BOS, e, m, m, a, BOS]
```

**看懂就算过关**：

- 为什么要把字母变成数字？  
- BOS 为什么既当「开始」又当「结束」？  
- 词汇表为什么是 27？  

#### Day 3～4：损失与「预测下一个字」

- 读 README「训练循环」里关于交叉熵的部分（先不看 Adam）  
- 记住公式直觉：`-log(正确 token 的概率)` —— 越确定正确答案，损失越低  
- 随机猜 27 选 1 时，loss ≈ 3.3；训练后降到 ~2.3 说明在学习  

**验收**：能解释「训练就是让模型对下一个字母更不惊讶」。

#### Day 5～7：复习 + 通俗笔记

- 精读 [知识点通俗版](20260917-1315-知识点通俗版.md) 第一～二站  
- 可选：[数据处理](20260917-1124-数据处理.md)、[分词器](20260917-1124-分词器.md)  

**本周打卡题**：关掉文档，口述「从名字文件到数字序列」的全过程。

### 第 2 周 —— 自动微分（全项目最难、也最值得）

**目标**：理解 `Value` 类：前向算数值、反向算梯度、用梯度调参数。

#### Day 1～2：先建立直觉，再看代码

1. 浏览器打开 **`autograd_demo.html`**，跟着交互理解  
2. 读 README「自动微分」章节中的小例子（a=2, b=3, L=a*b+a）  
3. 再读 `microgpt.py` 里 `Value` 类（`__add__` / `__mul__` / `backward`）  

**生活类比**（来自通俗版）：调汤——尝一口知道该加盐还是减盐；梯度 = 方向 + 幅度。

#### Day 3～4：手算一个迷你例子

在纸上或 Python REPL 里做：

```python
a = Value(2.0)
b = Value(3.0)
c = a * b      # 6
L = c + a      # 8
L.backward()
# 期望：a.grad == 4, b.grad == 2
```

**必须搞懂**：

- `data` vs `grad`  
- `_children` / `_local_grads` 记的是什么  
- `backward` 为什么要拓扑排序、为什么用 `+=`  

#### Day 5～7：巩固

- 文档：[自动微分](20260917-1124-自动微分.md)、通俗版第三站  
- 视频（强烈推荐）：Karpathy micrograd 教程（README 中有链接，约 2.5 小时，可分多次看）  

**本周打卡题**：不用看代码，画出 `L = a*b + a` 的计算图，并标出各边局部梯度。

---

### 第 3 周 —— GPT 架构（注意力 + MLP）

**目标**：看懂 `gpt()` 函数：一个 token 如何变成「下一个 token 的分数」。

#### Day 1：嵌入 + 辅助函数

- `wte` / `wpe`：token 嵌入、位置嵌入  
- `linear`、`softmax`、`rmsnorm`  
- 打开 **`softmax_demo.html`**、**`rmsnorm_demo.html`**  

#### Day 2～4：注意力（Attention）——「token 之间的通信」

- 打开 **`attention_demo.html`**  
- 读 `gpt()` 里 Q/K/V、多头、KV cache、残差连接  
- 类比：Q=我在找什么，K=我有什么，V=被选中时提供什么  

**验收**：能解释「为什么注意力是模型看历史字符的唯一地方」。

#### Day 5：MLP ——「单个位置上的思考」

- 两层线性 + ReLU，维度 16 → 64 → 16  
- 与注意力交替：通信 → 计算 → 通信 → 计算  

#### Day 6～7：串起来

- 文档：[模型架构](20260917-1124-模型架构.md)、[推理生成](20260917-1124-推理生成.md)  
- 对照 README「架构」整章，在代码里标出：嵌入 → 注意力 → MLP → lm_head  

**本周打卡题**：用自己的话画一张「单个 token 前向传播」流程图（不必精准到公式）。

---

### 第 4 周 —— 训练、推理、动手改造

**目标**：看懂训练循环与采样；通过小改动验证理解。

#### Day 1～2：训练循环 + Adam

- 每步：取一个名字 → 前向算 loss → `backward` → Adam 更新参数 → 清零 grad  
- 文档：[优化器](20260917-1124-优化器.md)  
- 先接受「Adam 比裸梯度下降更稳」；细节可后啃  

#### Day 3：推理与温度

- 从 BOS 开始，采样 → 反馈 → 直到 BOS 或达到长度  
- 改 `temperature`（如 0.2 / 0.5 / 1.0 / 1.5），观察名字风格变化  

#### Day 4～7：动手实验清单（选做 ≥ 3 项）

| 实验 | 改什么 | 观察什么 |
|------|--------|----------|
| A | `num_steps` 改为 200 / 3000 | loss 曲线与名字质量 |
| B | `n_embd` / `n_layer` 稍微加大 | 变慢但可能更好？ |
| C | 换数据集（城市名、宝可梦名、短中文拼音等） | 模型学新分布 |
| D | 打印某个 step 的 `probs`，看对下一字母的信心 | 训练是否在「变准」 |
| E | 把 `temperature` 做成命令行参数 | 工程化小练习 |

**本周打卡题**：向朋友讲 5 分钟——「microgpt 和 ChatGPT 算法上相同的是什么、不同的是什么」。

答案提纲：相同 = 预测下一个 token；不同 = 数据规模、分词、算力、工程、后训练（SFT/RL）。详见 README「真实世界」章节。

## 四、按模块的「读代码地图」

读 `microgpt.py` 时按这个顺序，不要从头看到尾硬啃：

| 顺序 | 模块 | 约略位置（以文件内注释「第N部分」为准） | 配套资源 |

| ③ | Value / backward | 第3部分 | `autograd_demo.html`；自动微分文档 |

| 阶段概念 | 含义 |
|----------|------|
| Bigram 计数 | 无神经网络，只统计「字母对」频率 |

| Value 自动微分 | 对应本文件第3部分 |
| 单头注意力 | 对应注意力核心，先理解再看多头 |

## 八、常见卡点与对策

| 卡点 | 对策 |
|------|------|
| 畏惧微积分 | 只记「局部变化率相乘＝链式法则」；先看 autograd 演示和手算例子 |
| 注意力公式晕 | 先看 `attention_demo.html`，再回代码；先理解单头再看多头循环 |
| Adam 公式多 | 先当作「聪明的梯度下降」；弄懂 `p.data -= ...` 和 `grad=0` 即可 |
| 训练太慢 / 想改大模型 | 初学保持默认超参；弄懂后再加 `num_steps` |
| 中文/别的数据效果差 | 字符集变了词汇表会变；先用全小写英文或拼音，降低变量 |

## 十、一句话总结

> 把 `microgpt.py` 当成一本「可以运行的教科书」：先跑通 → 按 数据/分词/梯度/结构/训练/推理 六块啃 → 每块配一个演示或小实验 → 最后能讲清它与 ChatGPT 同构。

按本计划执行 2～4 周，你就不再是「会调用 API 的用户」，而是「理解下一个 token 预测」的入门学习者。

祝学习顺利。有卡点时，优先回到代码注释和通俗版文档，而不是急着看更新更大的模型论文。
