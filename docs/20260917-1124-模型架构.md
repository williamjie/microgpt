# 模型架构（Transformer）详解

> 组件四：模型 | 关联代码：[microgpt.py 第4、5部分](../microgpt.py#L307-L608)

## 通俗解释

### 一场"先讨论、再思考"的会议

把 Transformer 的每一层想象成一场会议，每个 token（字母）是与会者：

1. **注意力 = 讨论环节**：每个字母环顾之前出现过的字母，问"你们谁的信息对我有用？"然后按相关程度把别人的信息"抄"一部分过来
2. **MLP = 思考环节**：每个字母拿到讨论成果后，回到自己座位独立消化、加工

一层会议 = 一次讨论 + 一次思考。层数越深，"会议"开得越多，信息提炼得越充分。

### Q、K、V 三个角色

注意力里有三个角色，可以类比**图书馆检索**：

- **Q（Query，查询）**："我想找什么信息？"——好比检索关键词
- **K（Key，钥匙）**："我这里有什么信息？"——好比每本书的标签
- **V（Value，内容）**："选中我的话，我能给你什么？"——好比书的正文

当前字母拿自己的 Q 去和每个历史字母的 K "对暗号"（点积），暗号对得越准，就越能拿到对方的 V。

### 举例：预测 "emma" 第二个 m 后面的字母

模型的 Q 可能是"我在找元音"，而前面 'e' 的 K 恰好匹配"我包含元音信息"，于是 'e' 获得高注意力权重，它关于元音的信息（V）流入当前位置，帮助模型预测出 'a'。

## 专业解释

### 总体结构

```text
输入 token → 词嵌入 + 位置嵌入
    → RMSNorm → 多头注意力 → 残差
    → RMSNorm → MLP(16→64→16) → 残差
    → lm_head 投影 → 27 维 logits
```

遵循 GPT-2 的三处现代化简化：**RMSNorm 替代 LayerNorm**（去掉均值中心化）、**ReLU 替代 GeLU**、**去掉全部偏置**。

### 各组件的数学形式

**嵌入**：token 与位置分别查表后相加

$$x = \text{wte}[token] + \text{wpe}[pos]$$

**RMSNorm**：按均方根缩放，稳定激活值量级

$$\hat{x}_i = \frac{x_i}{\sqrt{\frac{1}{d}\sum_j x_j^2 + \epsilon}}$$

**缩放点积注意力**（每个头 head_dim=4）：

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

除以 $\sqrt{d_k}$ 的原因：点积方差随维度线性增长，不缩放会导致 softmax 过于尖锐、梯度消失。

**MLP**：两层全连接夹一个非线性

$$\text{MLP}(x) = W_2 \cdot \text{relu}(W_1 x)$$

中间维度扩展 4 倍（16→64）提供更大的非线性表达空间。

**残差连接**：`x = block(x) + x`。加法运算的局部梯度为 1，梯度可以无衰减地直通反向传播，是深层网络可训练的关键。

### 独特之处：训练中也用 KV Cache

常规实现训练时一次并行处理整个序列，推理时才引入 KV Cache。microgpt 每次只处理**一个 token**（无批次、无并行时间步），所以 K/V 显式追加到缓存列表。更特别的是：**缓存中的 K/V 是计算图中的活跃 Value 节点**，反向传播会穿透整个缓存——数学上等价于对完整序列注意力做反向传播，只是把"并行"换成了"循环 + 缓存"。

### 4,192 个参数的去向

| 参数 | 形状 | 数量 |
|------|------|------|
| wte 词嵌入 | 27×16 | 432 |
| wpe 位置嵌入 | 16×16 | 256 |
| QKVO 注意力 | 4 × 16×16 | 1,024 |
| MLP fc1/fc2 | 64×16 + 16×64 | 2,048 |
| lm_head 输出 | 27×16 | 432 |
| **合计** | | **4,192** |

GPT-2 有 16 亿参数，GPT-4 级别有数千亿——结构相同，规模差 6 个数量级以上。
