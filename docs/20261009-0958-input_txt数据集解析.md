# input.txt 是什么？——microgpt 训练数据集解析

## 一、结论

`input.txt` 是本项目（microgpt）的**训练数据集（语料库）**：一个包含 **32,033 个英文名字**的纯文本文件，每行一个名字、全小写，从 `emma` 开始，到 `zzyzx` 结束，文件大小约 228KB。

它的身份是 **Andrej Karpathy makemore 项目的 `names.txt`**。`microgpt.py` 启动时会检查本地是否存在 `input.txt`，不存在则自动从 GitHub 下载：

```python
if not os.path.exists('input.txt'):
    import urllib.request
    names_url = 'https://raw.githubusercontent.com/karpathy/makemore/988aa59/names.txt'
    urllib.request.urlretrieve(names_url, 'input.txt')
docs = [line.strip() for line in open('input.txt') if line.strip()]
random.shuffle(docs)
print(f"num docs: {len(docs)}")
```

## 四、数据特点

1. **按字母表分块**：文件内多个 A→Z 轮次。前段以女性名字为主（emma、olivia、gwendoline…），中后段出现大量男性名字（kaesen、khaiden、kingdom、tigran…）。
2. **大量拼写变体**：同一名字有多种变体写法，例如 `breck` / `breckin` / `brekkyn`、`ryelynn` / `raylinn` / `rayanne`，利于模型学习字母级统计规律。
3. **混合中性名**：散落 unisex 名字（如 `harris`、`harvey`、`maven`、`londyn`）。
4. **纯净、小体量**：无标点、无数字，仅 228KB，适合教学级快速训练（microgpt 主打零依赖、200 行代码跑通）。

## 五、在本项目中的作用

`input.txt` 是 microgpt（Andrej Karpathy 2026 年 2 月发布的 200 行纯 Python GPT）的唯一训练数据。项目流程：

1. 读取 `input.txt`，每行作为一篇"文档"（doc）；
2. 随机打乱（`random.shuffle`）后喂给字符级分词器；
3. 用内置的 autograd + 类 GPT-2 架构 + Adam 训练；
4. 推理时模型"学会"名字的统计模式，**生成全新的、听起来合理的名字**。

按 README 的预告，训练结束后模型会产出类似如下结果：

```
sample  1: kamon
sample  2: ann
sample  3: karai
```

- `input.txt` 不是配置或代码，而是 **microgpt 的全部训练语料**。
- 内容 = 32,033 个英文名的列表（源自 makemore `names.txt`）。
- 作用 = 让 200 行的迷你 GPT 学会"如何拼出一个像名字的词"。
