## 一、后端开发工程师核心知识

### 1.1 编程基础与计算机基础 ⭐

- **编程语言**：精通至少一门主流语言，理解其底层机制
  - Java：JDK 17/21（LTS）、JVM 内存模型、GC 机制、类加载、并发包（JMM、AQS、虚拟线程）
  - Go：goroutine/channel、GMP 调度模型、GC 原理、零拷贝与逃逸分析
  - Python / Node.js / Rust 等按技术栈掌握其一
- **数据结构与算法**：数组/链表/栈/队列/哈希；二叉树、红黑树、⭐B+ 树（数据库索引核心）；排序/查找/动态规划；时间与空间复杂度分析
- **操作系统**：进程/线程/协程、内存管理、⭐I/O 模型（阻塞/非阻塞/多路复用 epoll、零拷贝）、上下文切换、并发原语（互斥锁/条件变量/原子操作）
- **计算机网络**：⭐TCP 三次握手/四次挥手、流量与拥塞控制；HTTP/1.1、HTTP/2、HTTP/3；⭐HTTPS 与 TLS 握手流程；DNS 解析；负载均衡与代理；WebSocket
- **编程基本功**：设计原则（SOLID、高内聚低耦合）、异常与边界处理、代码可读性与重构

### 1.2 数据库 ⭐

- **关系型数据库（以 MySQL 为主）**
  - InnoDB 存储引擎、⭐B+ 树索引、聚簇/二级索引、最左前缀原则
  - 事务与 ACID、⭐隔离级别（RR/RC）、MVCC、undo log
  - 锁机制（行锁/间隙锁/意向锁）、死锁分析、⭐慢查询定位与优化（explain、索引失效场景）
  - 主从复制、半同步、MGR 高可用；备份恢复与主从切换
- **分库分表**：⭐分片键选择（哈希/范围/列表）、ShardingSphere/MyCat、全局 ID、跨分片查询与翻页、在线 DDL 与大表改造
- **NoSQL 与新范式**
  - ⭐Redis：核心数据结构、淘汰策略、持久化、⭐缓存三大问题（穿透/击穿/雪崩）与多级缓存、Redis Cluster
  - MongoDB（文档型）、HBase/Cassandra（宽表）、时序库、图数据库
  - 向量数据库：pgvector / Milvus / Qdrant（AI 时代应用检索标配）
- **OLAP**：ClickHouse / Doris / StarRocks，实时数仓场景

### 1.3 Web 开发框架

- Java 生态：⭐Spring Boot（自动装配、 starter、配置管理）、Spring Cloud（微服务全家桶）、AOP、声明式事务、JVM 调优入门
- 其他栈：Go（Gin/Echo/Fiber）、Python（Django/FastAPI）、Node.js（NestJS/Express）
- 领域建模入门：⭐DDD 基本概念（实体/值对象/聚合根/仓储/领域事件）

### 1.4 API 设计与接口规范

- ⭐RESTful 资源建模、接口版本管理、统一错误码与分页约定
- ⭐接口幂等设计（唯一索引、状态机、token 防重放）
- gRPC / Protobuf（双向流、服务间通信）、GraphQL
- OpenAPI（Swagger）规范、契约测试（Consumer-Driven Contracts）

### 1.5 中间件 ⭐

- **消息队列**：Kafka / RocketMQ / RabbitMQ
  - 投递语义：at-least-once / exactly-once；⭐顺序消息；事务消息（分布式事务方案之一）
  - 重试与死信队列、消费幂等、分区扩容与消费位点
- **缓存**：Redis 缓存模式（cache-aside / 读写穿透策略）、热点探测、缓存一致性（先更新 DB 再删缓存、延迟双删）
- **任务调度**：XXL-Job / ElasticJob，分片调度、失败转移
- **搜索引擎**：Elasticsearch（倒排索引、分片与副本、mapping 与查询 DSL、深分页问题）
- **日志与观测**：ELK/Loki、⭐Prometheus + Grafana、OpenTelemetry 链路追踪（SkyWalking/Jaeger）
- **API 网关**：Nginx/Kong/APISIX，路由、限流、鉴权、协议转换

### 1.6 微服务体系

- 服务拆分：⭐业务域边界（DDD 战略设计/上下文映射）、康威定律（团队结构决定系统结构）
- 注册与配置：Nacos / Consul / Eureka；配置中心热更新
- ⭐服务治理：熔断（Hystrix/Sentinel/Resilience4j）、降级、限流（令牌桶/漏桶/滑动窗口）、重试与超时
- 服务间通信：HTTP vs gRPC 选型、同步 vs 异步（消息驱动）
- 服务可观测：指标（RED/USE 方法）、日志规范（结构化 JSON、traceId 贯穿）

### 1.7 分布式系统 ⭐

- ⭐CAP 定理、PACELC、BASE（最终一致性的工程化）
- 共识协议：Raft / Paxos / ZAB 原理与选型（etcd / ZooKeeper）
- ⭐分布式事务：2PC（强一致、阻塞）、TCC（Try-Confirm-Cancel）、Saga（长事务、补偿）、消息 + 本地消息表；按一致性强度与性能取舍
- 分布式锁：Redis（RedLock 争议与替代）、ZK / etcd 临时节点
- ⭐幂等性设计、分布式 ID（Snowflake 时钟回拨处理）
- 一致性哈希（分片与扩容）、数据复制、Quorum（W+R>N）、Gossip 协议
- 容错机制：超时与重试策略、背压（backpressure）、优雅降级与流量整形

### 1.8 高可用与性能

- ⭐负载均衡：四层（LVS/DPDK）vs 七层（Nginx/Envoy）、加权轮询/最少连接/一致性哈希
- 高可用架构：多副本、双机热备、多机房/同城双活/异地灾备；RPO 与 RTO 指标
- 性能调优：连接池/线程池参数、JVM 调优、SQL 调优、I/O 优化（epoll、mmap、零拷贝）
- 测试：单元测试（JUnit/pytest、覆盖率）、集成测试、⭐压测（JMeter/k6/Locust）、故障演练（ChaosBlade）

### 1.9 工程化、DevOps 与安全

- Git 工作流（trunk-based / git flow）、⭐CI/CD（Jenkins / GitLab CI / GitHub Actions）、代码评审、静态检查（sonar/spotbugs）
- 容器化：⭐Docker（多阶段构建、镜像优化）、⭐K8s 基础概念（Deployment/Service/Ingress/ConfigMap/探针/HPA）
- 基础设施即代码：Terraform / Ansible；GitOps（ArgoCD/Flux）
- ⭐安全：OWASP Top 10（注入/越权/敏感数据明文存储）、认证授权（OAuth2/OIDC/JWT）、密钥管理、数据脱敏、依赖与供应链安全
- SRE 基础：⭐SLI/SLO/SLA、错误预算、on-call 文化与事故复盘（postmortem）

### 1.10 AI 时代新增技能（2025–2026 趋势）

- LLM 集成：⭐RAG（检索增强）、Function/Tool calling、Agent 编排（ReAct/多智能体）、上下文工程
- 向量检索：向量库选型、embedding 更新与召回策略、混合检索（向量 + 关键词）
- AI 工程化：prompt 版本管理、evals 评测集、模型路由与降级、推理成本监控
- 前沿基础设施：eBPF 可观测性、服务网格（Istio）、Serverless/FaaS、边缘计算

## 二、架构师额外需要掌握的知识点

> 架构师 = 后端全栈深度 + 系统级设计决策能力 + 业务与组织视角。以下按「增量」组织，与第一章互补。

### 2.1 系统设计与建模 ⭐

- 将业务需求转化为技术蓝图：⭐架构决策记录（ADR）、需求/约束/目标三要素
- ⭐架构风格：分层、微服务、事件驱动（EDA）、CQRS、事件溯源（Event Sourcing）、六边形/整洁架构
- C4 模型（Context / Container / Component / Code）做多视图表达
- ⭐非功能需求权衡框架：复杂度 vs 稳定性（简单场景别上分布式，避免过度设计）、成本 vs 容灾（中小业务单集群，核心业务多机房多副本）、实时性 vs 吞吐量（低延迟同步、高吞吐异步批量）
- 容量估算（手算）：用户规模 → 峰值 QPS → 数据量 → 存储/带宽/机器数，形成「量级感」

### 2.2 数据架构

- 数据分层：ODS/DWD/ADS、数据湖 vs 数据仓、流批一体（Flink/Spark）
- ⭐存储选型矩阵：结构化 / 半结构化 / 向量 / 时序 / 图，各场景 TCO 与运维成本
- 主数据治理、数据血缘、数据一致性（最终一致下的对账机制）
- 核心数据库深度：⭐MySQL 高可用体系（MGR/半同步、主从切换、备份恢复演练）、分库分表演进路线

### 2.3 云原生架构

- ⭐K8s 深入：调度器（污点/亲和/Pod 优先级）、CNI 网络（Overlay vs 裸金属 eBPF）、CSI 存储、HPA/KEDA 弹性
- 服务网格（Istio/Linkerd）：东西向流量治理、mTLS、可观测下沉 sidecar
- GitOps、多集群/多云策略、服务网格 + 服务治理去中心化趋势
- Serverless（FaaS/分布式函数）与边缘计算（MEC/WASM on edge）

### 2.4 大规模与高并发架构

- 瓶颈识别：⭐Amdahl 定律、木桶效应；单机 → 集群 → 分片 → 多机房演进路线
- 经典方案：⭐读写分离、分库分表、单元化（Unit）架构、异地多活（流量调度、数据双写与校验）
- 海量数据：冷热分离、对象存储（S3/MinIO）、数据归档、采样与降维
- 性能与成本：⭐FinOps（资源利用率、单位业务成本模型）、缓存分层（本地 Caffeine + 远端 Redis）、GPU/推理资源池化

### 2.5 技术选型与权衡 ⭐

- 选型方法论：TCO、成熟度、社区活跃度、团队技术栈匹配；⭐POC 验证 → RFC 评审 → ADR 落档
- 权衡直觉：避免过早分布式、避免过早抽象；「简单场景单库单表优于分库分表」等反过度设计原则
- 安全与合规架构：零信任、认证授权统一（OAuth2/OIDC/SCIM）、⭐数据合规（个保法/跨境数据）、密钥与审计
- 技术债管理：识别、量化、偿还排期（20% 时间预算）

### 2.6 工程效能与组织

- 平台工程：内部开发者平台（IDP）、Golden Path、自助式基础设施
- 变更管理：⭐灰度发布（金丝雀/蓝绿/影子流量）、发布回滚预案、变更三板斧（可监控/可灰度/可回滚）
- 技术风险管理：故障演练（Chaos 工程）、容量水位线、依赖方风险清单
- 团队与技术规划：技术 roadmap、能力矩阵与培养路径、招聘画像与梯队

### 2.7 软技能（架构师的分水岭）

- ⭐业务理解与产品思维：从业务目标反推系统指标（不是从技术出发）
- 沟通与表达：⭐架构图 + 决策文档（为什么选 A 不选 B）、向上管理与跨团队说服
- 技术影响力：技术布道、规范制定、Code Review 文化
- 导师能力：给初级/中级开发者设计成长路径与任务

### 2.8 前沿趋势（持续跟踪，非必精通）

- ⭐AI 原生架构：LLM 推理基础设施（KV Cache、请求调度、serving 框架 vLLM/TensorRT-LLM）、AI Gateway（模型路由/多模型降级）、Multi-Agent 编排框架
- 向量检索规模化：ANN 算法（HNSW/IVF）、混合召回、GPU 加速索引
- eBPF 时代：可观测、网络加速、安全（Runtime 级）
- WebAssembly 服务端化（WASI）：插件化、边缘、Sandbox 隔离
- 低时延计算：RDMA、存算分离架构（如 Snowflake/Databricks 范式）

## 三、分阶段学习路径建议

| 阶段 | 年限 | 目标 | 关键动作 |
|:---|:---:|:---|:---|
| 初级 | 0–2 | 独立完成 CRUD 级需求并稳定交付 | 语言与框架熟练、SQL 与索引、HTTP 全流程、单测、读日志定位问题 |
| 中级 | 3–5 | 独立负责模块，能讲清原理 | 数据库与中间件深入、高可用与性能、分布式基础、CI/CD 全流程 |
| 高级 | 5–8 | 跨模块系统设计，主导一次大版本 | 系统设计（容量估算）、架构选型与落地、跨团队协作、故障应急 |
| 架构师 | 8+ | 对系统长期演进负责 | 架构决策（ADR）与权衡、数据/云原生架构、技术路线图、成本与人效 |

- **自检方法**：用「面试高频题清单」反向检验（每个 ⭐ 条目自问：能否白板推导原理？能否举出一次实战？），建立个人知识卡片。
- **项目练习**：手写 KV 存储、短链服务（缓存 + 分片 + 幂等）、分布式限流器（令牌桶 + Redis）、RAG 小应用（向量检索 + 混合召回）。
