# 自动微分（Autograd）详解

> 组件三：自动微分 | 关联代码：[microgpt.py 第3部分 Value 类](../microgpt.py#L98-L305)

## 通俗解释

### 旋钮问题

训练神经网络就像调一台有几万个旋钮的收音机：每个旋钮拧一点，声音（损失）会变好或变差。要高效调音，你需要知道**每个旋钮该往哪边拧、拧多少**——这就是"梯度"。

### 智能数字：Value

`Value` 是一个"会记账的数字"。普通数字像一张照片，只有最终结果；`Value` 像一段录像，记住了自己是怎么算出来的：

```python
a = Value(2.0)
b = Value(3.0)
c = a * b      # c 记住了："我是 a 和 b 相乘得来的"
```

每次运算，`Value` 都做两件事：
1. **算结果**（前向传播）：`c.data = 2 × 3 = 6`
2. **记下敏感性**（局部梯度）："a 变 1 我变 3，b 变 1 我变 2"

### 多米诺骨牌：反向传播

训练结束时我们从损失往回推。链式法则就像多米诺骨牌：推倒第一张牌的力量，沿链条逐级传递。比如 a → b → Loss，Loss 对 b 敏感、b 对 a 敏感，那么 Loss 对 a 的敏感度就是两者相乘。

一个关键细节：梯度累加用 `+=` 而不是 `=`。如果一个数字被用了两次（图分叉了），它的梯度是两条路径贡献的**总和**：

```python
a = Value(2.0); b = Value(3.0)
L = a * b + a      # a 参与了两条路径
L.backward()
print(a.grad)      # 4.0 = 3（经过乘法路径）+ 1（经过加法路径）
```

这与 PyTorch 的 `tensor.backward()` 是**同一个算法**，只是作用在标量而不是张量上。

## 专业解释

### 计算图与反向模式自动微分

自动微分（AD）有两种模式：前向模式（一次算一个输入方向的导数）和**反向模式**（一次算出输出对所有输入的导数）。反向模式在输入数量远大于输出（损失只有 1 个标量、参数有 4192 个）时效率碾压，这正是神经网络选择它的原因。

`Value` 节点构成有向无环图（DAG）。每个节点 $v$ 存储：

- $v.\text{data}$：前向计算值
- $v.\text{grad} = \frac{\partial L}{\partial v}$：损失对该节点的导数
- $(v._\text{children}, v._\text{local\_grads})$：子节点及局部导数 $\frac{\partial v}{\partial c}$

### backward() 的算法

```text
1. DFS + 后序遍历 → 拓扑排序 topo（保证子节点先于父节点入栈）
2. self.grad = 1                       # ∂L/∂L = 1
3. 逆序遍历 topo：
       对每个 (child, local_grad)：
           child.grad += local_grad × v.grad
```

核心公式即多元链式法则：

$$\frac{\partial L}{\partial c} = \sum_{v \in \text{children}(c)} \frac{\partial v}{\partial c} \cdot \frac{\partial L}{\partial v}$$

求和对应图的多路径贡献——这就是用 `+=` 的数学理由。

### 六种基本运算的局部导数

| 运算 | 前向 $v$ | 局部梯度 $\partial v/\partial a$ | 备注 |
|------|----------|----------------------------------|------|
| $a + b$ | $a+b$ | $1$ | 加法梯度直通，残差连接的基础 |
| $a \cdot b$ | $ab$ | $b$ | 梯度携带"对方"的值 |
| $a^n$ | $a^n$ | $n \cdot a^{n-1}$ | 幂法则 |
| $\ln a$ | $\ln a$ | $1/a$ | 交叉熵损失依赖 |
| $e^a$ | $e^a$ | $e^a$ | 导数等于自身，softmax 依赖 |
| $\text{relu}(a)$ | $\max(0,a)$ | $\mathbf{1}_{a>0}$ | 负区梯度被"关断" |

复合运算（减法、除法等）全部由这 6 种组合而来，例如 $a/b = a \cdot b^{-1}$。

### 工程要点

- **`__slots__`**：固定实例属性布局，省去每个对象的 `__dict__`。一个训练步会创建数万个 Value 节点，内存收益可观
- **局部梯度在前向时即时计算**：避免了反向时重复求值（如 `exp` 的导数就是前向结果）
- **无张量化**：PyTorch 的 `backward()` 是同一算法的张量并行版本——数学相同，差的是效率，完美印证"其他一切都只是为了效率"
