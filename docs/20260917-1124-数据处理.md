# 数据处理（Dataset）详解

> 组件一：数据集 | 关联代码：[microgpt.py 第1部分](../microgpt.py#L39-L67)

## 通俗解释

想象你要教一个完全不懂英语的外星人"什么样的字母组合看起来像人名"。你的办法很朴素：给它看几万个真实的人名，让它自己找规律——比如"名字通常以辅音开头""th 经常连在一起""连续三个辅音很少见"。

这里的 GPT 模型就是那个外星人。它不认识任何单词，没有词典，没有语法书，唯一的知识来源就是这 3 万多行名字。

在 ChatGPT 的世界里，"文档"可以是互联网网页、书籍、代码仓库；而在 microgpt 里，一个"文档"就是一个名字，比如 `emma`。你和 ChatGPT 的一段对话，在它眼里也只是另一种形式的"文档"——用特殊标记分隔的文本而已。

## 专业解释

语言模型的训练数据本质上是**自监督文本语料**（self-supervised corpus）：不需要人工标注，任何连续文本都可以作为训练信号。形式化地，数据集定义为文档列表：

$$D = \{d_1, d_2, \dots, d_N\}, \quad d_i \in \Sigma^*$$

其中 $\Sigma$ 是字符集，$N = 32{,}033$（names.txt 的行数）。

训练目标是在该数据分布下最大化下一 token 的对数似然：

$$\max_\theta \sum_{d \in D} \sum_{t} \log p_\theta(x_{t+1} \mid x_{\le t}, d)$$

工程细节：

1. **按需下载**：`input.txt` 不存在时通过 `urllib.request.urlretrieve` 从 makemore 仓库拉取，保证脚本开箱即用
2. **清洗**：逐行 `strip()` 去掉空白与空行，保证每个文档非空
3. **打乱（shuffle）**：`random.shuffle(docs)` 消除数据集的原始排列偏差，配合 `docs[step % len(docs)]` 的循环采样，使每个 epoch 内文档顺序近似随机
4. **无验证集/测试集划分**：这是教学简化，生产训练必须有 held-out 评估集来监控过拟合

## 与生产系统的差距

| 维度 | microgpt | 生产级 LLM |
|------|----------|-----------|
| 数据量 | 32K 个名字，约 18 万字符 | 数万亿 token |
| 来源 | 单一文件 | 网页/书籍/代码多源混合 |
| 预处理 | 仅 strip | 去重、质量过滤、毒性检测、领域配比 |
| 批处理 | 每步 1 个文档 | 每步数百万 token 的大批次 |
| 评估 | 无 | 困惑率、benchmark、人工评估 |
