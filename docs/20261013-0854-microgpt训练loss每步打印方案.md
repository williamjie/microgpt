### 1.2 训练循环与 loss 打印（重点）
- 训练循环位于 `microgpt.py:643-723`，`num_steps = 1000`（第 643 行）。
- 每一步：取一个名字 → 前向逐个位置预测 → 计算交叉熵损失 → 反向传播 → Adam 更新参数。
- 损失在 `microgpt.py:682` 计算：`loss = (1 / n) * sum(losses)`，`loss.data` 为普通 Python float。
- 训练进度打印在 `microgpt.py:720`：

```python

```

  - `end='\r'` 是**回车符（不换行）**：每一步把光标移回行首，覆盖上一行内容。

- 用户明确希望"每步都打印出来，不要覆盖"（如 `step 160 / 1000 | loss 2.1104`）。

## 2. 修改方案

### 2.1 目标
- 每一步换行打印一行 loss，不覆盖、不丢历史。
- 格式与示例一致：`step <当前步> / <总步数> | loss <4 位小数>`。
- 仅改打印方式，不动训练逻辑、loss 计算、性能（只改 I/O）。

### 2.2 具体改动
文件：`e:/company_code/microgpt/microgpt.py`

第 720 行（旧 → 新）：

| 项 | 内容 |
|----|------|
| 旧 | `print(f"step {step+1:4d} / {num_steps:4d} | loss {loss.data:.4f}", end='\r')` |
| 新 | `print(f"step {step+1} / {num_steps} | loss {loss.data:.4f}")` |

改动点说明：
1. 去掉 `end='\r'` → 默认 `end='\n'`，每行独立打印，互不覆盖。
2. 去掉 `{step+1:4d}`、`{num_steps:4d}` 的宽度填充 `:4d` → 与用户示例 `step 160 / 1000` 对齐（去掉填充仅为对齐样式；若希望保留右对齐列式效果，可保留 `:4d`，二选一，不影响"不覆盖"目标）。

### 2.3 影响与注意点
- 输出量：`num_steps=1000` → 训练阶段约 1000 行日志，终端可读、可接受。
- 若后续把 `num_steps` 调大到数万级，逐行打印会刷屏；建议后续增强（**不在本次范围**）：① 落盘到 `train.log`；② 每 N 步打印一行 + 保留逐行可选开关。本次只做"逐行打印"最小改动。
- 对推理段（第 752 行起 `print("\n--- inference ---")`）无影响；去掉 `\r` 后训练最后一行自带换行，推理输出自然另起一行，更整洁。
- 不涉及模型、loss、优化器任何逻辑改动，训练结果与改动前一致。
